CEFI data processing pipeline

  1. fork the https://github.com/NOAA-CEFI-Portal/regional_mom6
  1. git clone git@github.com:NOAA-CEFI-Portal/regional_mom6.git (or the fork version)
  1. conda env create -f environment-dev.yml
  1. transfer data from GFDL to PSL in /Project/CEFI/private/scratch/FOLDER_NAME through globus
  1. preprocessing (add meta data, chunking, put files to the CEFI structured folder on PSL server)

        The script and the config file will be exeucted as python script config. The log file will be in the same name as the config file and located in the same folder as config file

        Explaining the order of the prefect pipeline above:

        1. the order are regrid ⇒ rotate vector ⇒ regrid again ⇒ calculate climatology
        1. the first regrid is to only regrid tracer point files
        1. the vector rotation process regrid the vector to tracer point and than perform the rotation as what was done by GFDL group
        1. the second regrid is to regrid the rotated fields that are not included in the first regrid
        1. the final step is to perform the calculation of all field on climatology

        All processing scripts are designed to skip files when the resulting file is already existed in the system. There is no overwriting happening. The only way to reprocess currently is to remove the file in the system and perform the processing again.

      1. run data processing with
        1. prefect server start (this start a prefect server for prefect to work)
        1. python prefect_flow_scripts.py prefect_flow_nep_hindcast.json (the prefect_flow_script basically submit one script and config out at a time and wait till its finished and submit the next script and confi in line)
